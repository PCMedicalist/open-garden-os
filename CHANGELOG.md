# Changelog

All notable changes to this project are documented here.

## [0.1.0] — 2026-11-27

### Added
- Typed, validated contracts for geolocation, weather, air humidity, ground moisture, growth monitors, virtualization manifests and camera overlays.
- `baseline_schedule` rule engine with evidence citations and safety bounds.
- `WateringMonitor` — optional local-LLM monitoring that fails loudly on hallucinated evidence, bad JSON, or inadequate model context.
- Synthetic field fixture (explicitly labelled synthetic) and 15 stdlib tests.
- Tier roadmap (Seed / Sprout / Canopy), privacy rules, architecture, sourced research notes, Apache-2.0 licence.

### Notes
- No hardware control, no agronomic advice, no cloud calls.
